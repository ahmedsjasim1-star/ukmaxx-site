Beyond the COA: why public batch sizes and live inventory matter.

How independent testing, release decisions and inventory records can create a clearer chain from laboratory report to supplied research product.

UKMAXX Team 8 min read Published 13 August 2026
On this page What a COA shows The batch chain Public batch size Live availability Purity and assay Rejected results Permanent records How to verify
Summary

A Certificate of Analysis shows what was found in a laboratory sample. It does not show how many units belonged to the batch, whether the result met the supplier's release specification, or whether that batch is still being supplied. UKMAXX publishes batch size, availability and release status alongside COAs to make that wider context visible.

A COA is an important part of research-product verification, but it is only one part of the chain.

A laboratory report may document sample identity, analytical method, purity, measured quantity and test date. Those details matter. However, the report normally describes the sample received by the laboratory; it does not automatically explain how that sample relates to the supplier's wider inventory.

That gap creates several practical questions. How many units were associated with the tested batch? Did the supplier release or reject it? Is the tested batch still current? When it is exhausted, will its record remain available? A transparent batch system should make those answers easier to find.

What a COA establishes - and what it does not

Independent analysis can establish what the laboratory found in the submitted sample. The exact result depends on the method used, but a useful report may include:

  • the submitted sample name or identity;
  • the analytical method, such as HPLC or UPLC-MS;
  • purity and, where tested, measured content or assay;
  • the laboratory, test date and report reference.

Those fields do not establish the size of the commercial batch, prove that every individual vial was analysed, record the supplier's release decision or show how much of the batch remains. Those are inventory and traceability questions, not laboratory-report fields.

A laboratory report should be treated as source evidence, not as a decorative badge or a complete inventory record.

From batch intake to permanent record

The UKMAXX process connects the laboratory result to a named batch and a visible decision. In simple terms, the chain is:

  1. Batch received.A supplier batch is assigned an internal batch code and starting quantity.
  2. Sample submitted.A sample is sent for independent analysis.
  3. Result reviewed.Purity, assay and other available findings are compared with the release specification.
  4. Release or reject.A passing batch can enter active inventory. A failed batch is not released.
  5. Public record created.The batch code, status, results and original report are connected in the checker.
  6. Inventory updated.Availability reduces as paid orders are allocated to that batch.
  7. Record archived.When the batch is exhausted or replaced, its history remains available.

The value lies in the connection between each stage. A report is stronger when it can be traced to a batch code, and a batch code is more useful when it leads back to the original evidence.

Why publish the original batch size?

Publishing the starting quantity gives the laboratory result an inventory context. If a released batch began with 29 units, that figure creates a defined boundary around the stock associated with that record.

Without a visible starting quantity, a report can remain on a website indefinitely while visitors have no way to tell how much product was ever connected to it. A batch-size record does not prove that every unit is identical, but it makes the supplier's traceability claim more specific and easier to question.

It also creates a clear rollover point. Once the recorded stock reaches zero, any later supply should belong to a new batch record with its own testing and release decision rather than inheriting an old report.

Why show live batch availability?

UKMAXX links paid-order inventory changes to the active batch record. When a unit is allocated to an order, the remaining quantity attached to that batch reduces. Where a bundle contains several units, its components are counted individually.

Original batch size minus allocated units equals remaining availability

This is not intended to manufacture urgency. Its purpose is to answer a narrower question: is this still the active tested batch, and how much recorded inventory remains before a new batch should be expected?

The live UKMAXX batch checker is the source for current figures. An article like this should explain the method rather than repeat stock numbers that can become outdated.

Why purity and assay should be read together

Purity and measured content answer different questions. Purity describes the proportion of detected material represented by the target compound within the analysed sample. Assay or content testing addresses how much target material was measured.

A sample can therefore show high purity while containing materially less target compound than its label claim. Looking at purity alone may create an incomplete impression. Where both values are available, publishing them together gives researchers a fuller view of the result and makes the release decision easier to understand.

The released BPC-157 5mg batch guide provides a live example: a 4.84mg assay is published alongside 99.746% HPLC purity and the original Janoshik record.

The released Retatrutide 10mg / RT10 guide follows the same format, publishing a 10.12mg assay beside 99.223% purity and its original report.

UKMAXX presents both fields on public batch records when they are included in the independent report. The original laboratory page remains the primary source and can be opened directly from the checker.

Rejected results belong in the record

Transparency is most meaningful when it includes results that did not meet the release specification. Publishing only successful reports can show what passed, but it says nothing about whether testing ever prevented a batch from reaching active stock.

UKMAXX's rejected Ipamorelin record illustrates the distinction between purity and quantity. Independent analysis reported high purity but measured content below the 5mg label claim. The 19-unit batch was not released for sale, and the checker records the reason for rejection alongside the laboratory result.

Keeping that record public serves two purposes. It explains why the batch never entered the catalogue, and it preserves evidence that the release decision followed the result rather than the other way around.

Passing analysis may release a batch. A result outside specification keeps it out of active inventory. Both outcomes form part of the testing history.

Why exhausted batches should remain visible

A batch does not stop being relevant when its final unit is supplied. Customers may still need to verify a code from an earlier order, and future visitors may want to see whether the testing history extends beyond whichever batch is currently active.

For that reason, exhausted records move into an archive rather than disappearing. Active, archived and rejected are different statuses, but all three contribute to the same historical chain:

Active

Released stock that is currently available.

Archived

A previous released batch retained for verification.

Rejected

A tested batch that did not enter active inventory.

This makes it harder for an old result to be presented as though it describes unlimited future stock. Each batch has its own code, evidence, starting quantity, status and place in the record.

How to verify a UKMAXX batch

  1. Enter the printed batch code in the public checker.
  2. Confirm that the product and batch identity match the item being checked.
  3. Review whether the record is active, archived or rejected.
  4. Compare the purity, assay and test date shown.
  5. Open the original laboratory record rather than relying only on the UKMAXX summary.
  6. Check the original batch size and current availability where applicable.

A QR code on the UKMAXX batch card leads to the same public checker. The destination remains stable while the records beneath it grow over time.

What this system does not claim

Public batch tracking does not mean that every vial was individually tested. It does not establish suitability for a particular experiment, safety, effectiveness or any clinical outcome. It also cannot replace a researcher's own review of the original laboratory evidence and handling requirements.

Its purpose is deliberately narrower: to connect an independently analysed sample to a named supply batch, make the release decision visible, show the inventory boundary around that record and preserve the outcome after the batch is no longer current.

Towards a more transparent verification standard

A COA becomes more useful when it sits inside a traceable system rather than standing alone. The combination of an original laboratory report, named batch, starting quantity, release status, changing availability and permanent history gives researchers more context with which to assess a supplier's documentation.

No single field provides the complete picture. The strength comes from making the connections public and allowing the record to be checked without asking the supplier for private documentation.
