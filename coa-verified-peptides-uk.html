Core COA fields to check

A useful peptide COA should connect directly to a batch code and show enough detail to verify what was tested. At minimum, look for the sample name, batch reference, lab name, method, test date and result.

Purity vs assay/content

Purity and assay are not the same thing. Purity describes how clean the tested material is, while assay or content result helps show how much target compound was found compared with the label claim.

This is why UKMAXX shows both where available. A compound can be very pure and still fail release standards if the vial content is materially below the label claim.

For a released example, the BPC-157 5mg batch guide shows the current batch's 4.84mg assay alongside its 99.746% HPLC purity result and original laboratory record.

The Retatrutide 10mg / RT10 guide provides another released example, pairing a 10.12mg assay with 99.223% purity and its public Janoshik report.

Why rejected batch records matter

Many sites only show successful results. UKMAXX also publishes rejected batch records because transparency is more valuable than pretending every supplier batch is perfect.

If a tested batch does not meet UKMAXX release specification, it is not released for sale and the batch checker explains why. Released products can be compared against the UK peptides overview before ordering.

COA verification FAQ

What does COA verified mean?

It means the batch is linked to a Certificate of Analysis showing details such as sample identity, method, purity or assay result, lab and test date.

How do I verify my UKMAXX batch?

Use the batch code from your order card or product label and search it on the UKMAXX COA checker.

Are failed batches hidden?

No. UKMAXX publishes rejected batch records when a batch does not meet release standards.
